# Guion de narración

## intro.mp3

En programación, almacenar información no siempre significa colocar todos los datos juntos. A veces, la mejor solución es crear conexiones entre ellos.

## referencias.mp3

Cada elemento de una lista enlazada recibe el nombre de nodo. Un nodo contiene un dato y una referencia que indica dónde se encuentra el siguiente elemento.

## insercion.mp3

La verdadera ventaja aparece cuando necesitamos modificar la estructura. En lugar de mover todos los elementos, solamente cambiamos las conexiones entre nodos.

## eliminacion.mp3

Eliminar un nodo no significa borrar toda la información posterior. Solo debemos actualizar las referencias necesarias para mantener la estructura.

## ventajas.mp3

Las listas enlazadas permiten crecer dinámicamente y modificar la información de manera flexible sin requerir posiciones consecutivas en memoria.

## desventajas.mp3

Sin embargo, esta flexibilidad tiene un costo. El acceso a los elementos es secuencial y cada nodo necesita memoria adicional para almacenar referencias.

## variantes.mp3

Las listas enlazadas pueden evolucionar. En una lista doblemente enlazada, cada nodo conoce al anterior y al siguiente. En una lista circular, el último nodo vuelve a conectarse con el primero.

## aplicaciones.mp3

Estas estructuras aparecen en muchas aplicaciones reales, como navegadores, reproductores musicales y sistemas donde los elementos deben recorrer ciclos continuamente.
